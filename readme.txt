STUDENT MANAGEMENT SYSTEM

1. PROJECT DESCRIPTION

Student Management System is a web-based application developed to manage
student information easily and efficiently.

2. OBJECTIVE

The main objective of this project is to provide a simple system to
register, view, edit, update, delete and search student details.

3. TECHNOLOGIES USED

HTML
CSS
JavaScript
LocalStorage

4. FEATURES

- Student Registration
- View Student Details
- Edit Student Details
- Update Student Details
- Delete Student Details
- Search Student
- Input Validation
- Duplicate Roll Number Checking
- Duplicate Email Checking
- LocalStorage Data Storage

5. HOW IT WORKS

The user enters student details such as Name, Roll Number, Email and
Branch. The details are validated and displayed in the student table.
JavaScript handles the operations and LocalStorage stores the student
data in the browser.

6. CONCLUSION

The Student Management System provides a simple and efficient way to
manage student information using web technologies.
